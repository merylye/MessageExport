One-time setup: allow access to your messages

macOS protects your Messages history. To let this app read it:

  1. Click Open System Settings.
  2. Turn on the switch next to Download My Messages. If it isn't listed, click + and choose the app.
  3. Quit this app and open it again.

Your messages stay on this computer. Nothing is uploaded.

Use an iPhone backup

Paste the path to a backup folder (it contains a file named Manifest.db).
